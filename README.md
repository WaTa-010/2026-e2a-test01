# やちよ日和

千葉県八千代市の観光スポットや地元グルメ、季節の楽しみを紹介する日本語の静的サイトです。

## 表示方法

`index.html` をブラウザーで開くと表示できます。ビルドやパッケージのインストールは不要です。写真と Web フォントの表示にはインターネット接続が必要です。

## GitHub Pages で公開

`main` ブランチへの push、または Actions の `Deploy to GitHub Pages` ワークフローを手動実行するとサイトをデプロイします。初回公開時は、GitHub リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択してください。

このリポジトリでの公開 URL は `https://wata-010.github.io/2026-e2a-test01/` です。デプロイ完了後は Actions の実行結果、または **Settings → Pages** から公開状態を確認できます。リポジトリの公開設定やアカウントの Pages 利用条件によっては、公開前に追加の設定が必要な場合があります。

## ファイル

- `index.html` — ページ本文とスポット情報
- `styles.css` — レイアウト、デザイン、レスポンシブ対応
- `script.js` — スポット絞り込みとモバイルメニュー

施設の営業状況や旬の時期は変わる場合があります。訪問前にリンク先の公式情報をご確認ください。
